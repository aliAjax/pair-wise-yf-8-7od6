# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计可放时长、筛选颜色偏移并生成试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 镜头组整理区

同一镜头的多条胶片素材可以从清单勾选建成一个镜头组：

- 组内每条素材保留各自的编号、时长和备注；
- 组头显示选用素材的合计**可放时长**（不含备用）；条目标为「备用」后不占可放时长，但仍留在组里；
- 一条素材不能同时进入两组；组内「移出」或整组「拆开」后，素材按原位置回到清单；
- 列表拖动以组为单位（拖组头 ⠿），散条移动时绕着整组走，不会插进组里；
- 筛选、破损提醒和导出都按分组后的新顺序与可放时长计算；
- 组关系、组名、备用标记保存在浏览器本地，关闭后重新打开仍在。

## 代码分层

- `grouping.js`：分组规则（纯数据操作，不碰 DOM，可独立测试）；
- `storage.js`：保存方式（localStorage 读写、旧存档迁移与脏数据清理）；
- `app.js`：页面交互（渲染、筛选、勾选、拖拽、导出）。

测试：`node test-grouping.js`（分组规则）、`node test-integration.js`（jsdom 整页交互）。
