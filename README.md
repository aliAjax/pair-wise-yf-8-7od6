# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移、把同一镜头的多条素材归为镜头组，并生成试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 镜头组整理区

- 在「放映顺序」清单里勾选同一镜头的未入组素材，右侧命名后「建成一组」；组内各自保留编号、时长、颜色、破损与备注。
- 组头显示**选用素材合计时长**；标为「备用」的条目不占可放时长，但仍留在组里（组头另列备用时长）。
- 一条素材同一时间只能属于一组；单条「拆出」或整组「拆开」后，素材按入组前的原位置回到清单。
- 拖动或 ↑↓ 调整顺序时，镜头组作为一个整块移动。
- 颜色/关键字筛选（关键字也匹配镜头组名）、试映前破损提醒、导出清单均沿用分组后的新顺序与备用时长规则；筛选状态下不允许拖动。
- 关闭页面再打开，组关系（含备用标记、原名位置）通过 localStorage 保留。

## 文件划分

- `grouping.js`：分组规则（建组、拆开、备用、整块移动、时长统计），纯逻辑不碰 DOM。
- `storage.js`：保存方式（localStorage 读写、旧存档迁移与去重）。
- `app.js`：页面交互（录入、勾选、渲染、拖拽、筛选、提醒、导出）。
- `index.html` / `styles.css`：结构与样式。
